# Bill C-12 后 asylum 安调压力下降对 PR/TR 安调周期的潜在影响预测报告

## 1. Executive Summary

本报告评估的问题是：**Bill C-12 生效后，如果加拿大 asylum/refugee front-end security screening 的新增 referral 明显下降，CBSA/security screening partners 是否可能把部分处理能力转向 PR 和 TR security screening，从而缩短 PR/TR 安调周期。**

核心结论如下：

2025 年，CSIS public report 显示 **Refugees / Front-End Screening** 为 **97,600 received**、**96,600 completed**；同一表中，PR security screening 为 **15,200 received / 16,900 completed**，TR security screening 为 **28,100 received / 24,000 completed**。因此，**97,600/year** 可以作为 2025 年 asylum/refugee security referral 的年度基准。([Canada][1])

Bill C-12 于 **2026 年 3 月 26 日获得 Royal Assent**。IRCC 官方说明，新的 asylum eligibility requirements 适用于 **2025 年 6 月 3 日或之后 made 的 claims**；其中 one-year ineligibility 规定，首次入境加拿大超过一年后才提出的 asylum claim **won’t be referred to the IRB**。([Canada][2])

加拿大政府 CIMM 材料显示，2025 年 inland asylum claimants 中，**59%** 在入境 12 个月内提出 claim；换言之，约 **41%** 不在这个 12 个月窗口内。同一材料也写明，等待 **12 个月或更久** 才提出 claim 的比例从 2024 年的 **12%** 上升到 2025 年的 **38%**，并说明越来越多人可能落入 Bill C-12 的新 ineligibility provisions。([Canada][3])

因此，本报告采用以下 post-C12 baseline scenario：

**97,600 × 59% = 57,584 ≈ 56,000/year**

也就是说，本报告将 **56,000/year** 作为 Bill C-12 后 asylum/refugee security referral 的基准情景。这个数字不是政府直接公布的 official forecast，而是基于政府公开比例推导出的 scenario assumption。

在该情景下，真正可能释放给 PR/TR 的 capacity 不应按 **97,600 - 56,000 = 41,600** 计算，因为这只是新增 referral 的下降量，不是处理能力本身。更合理的计算方式是：

**2025 asylum security output 年化能力 - post-C12 asylum security referral**

上传的 Security-Screening PDF 显示，2025 Jan–Nov asylum security output 合计 **71,653**；年化为 **71,653 / 11 × 12 = 78,167/year**。若未来 asylum security referral 降至 **56,000/year**，则理论净释放 capacity 为：

**78,167 - 56,000 = 22,167/year**

也就是约 **1,847/month**。

如果这部分 capacity 按 **TR 70%、PR 30%** 分配，则：

| 类别 |  2025 基准年处理能力 |  额外 capacity |           预测年处理能力 |
| -- | ------------: | -----------: | ----------------: |
| PR |  约 9,207/year |  +6,650/year | **约 15,857/year** |
| TR | 约 17,233/year | +15,517/year | **约 32,750/year** |

在中性情景下，本报告预测：

| 类别                    |   当前高压状态估计 |        中性改善后预测 |
| --------------------- | ---------: | -------------: |
| PR security screening | 约 30–55 个月 | **约 18–24 个月** |
| TR security screening | 约 25–40 个月 | **约 13–22 个月** |

如果 2026 年 asylum intake 进一步下降，并且 post-C12 asylum security referral 低于 56,000/year，比如降到 **43,000–50,000/year**，则 PR/TR 的预测还可以进一步改善：

| Future asylum security referral |          PR 预测周期 |          TR 预测周期 |
| ------------------------------: | ---------------: | ---------------: |
|                     56,000/year | **18–24 months** | **13–22 months** |
|                     50,000/year | **16–22 months** | **12–19 months** |
|                     45,000/year | **15–20 months** | **11–18 months** |
|                     43,000/year | **14–20 months** | **10–17 months** |
|                     40,000/year | **13–18 months** | **10–16 months** |

## 2. Data Definitions：三个口径必须分开

本报告涉及三个不同口径，不能混用。

### 2.1 Asylum claimants received

这是最前端的 claim 口径，指有人向加拿大提出 refugee protection request。你上传的 IRCC asylum spreadsheet 属于这一口径。该表显示：

|           年份 | Asylum claimants received |
| -----------: | ------------------------: |
|         2024 |                   171,840 |
|         2025 |                   113,105 |
| 2026 Jan–Feb |                    11,055 |

这个口径不是 security referral。它更接近 **gross asylum claims submitted / claimants received**，其中可能包括后来被 refer to IRB 的人，也可能包括后来被判定 ineligible 的人。

### 2.2 Asylum security referrals / Refugees front-end screening

这是更接近“难民/庇护安调 referral”的口径。CSIS 2025 public report 中，**Refugees / Front-End Screening** 为 **97,600 received**、**96,600 completed**。([Canada][1])

本报告用 **97,600** 作为 2025 asylum/refugee security referral 的基准。

### 2.3 Security screening output

这是处理能力口径。上传的 Security-Screening PDF 第 3 页列出 2024-Dec 到 2025-Nov 的 asylum、PR、TR monthly intake、output、historical inventory。该表显示，2025 Jan–Nov output 为：

| 类别     | 2025 Jan–Nov output |   月均 output |   年化 output |
| ------ | ------------------: | ----------: | ----------: |
| Asylum |              71,653 | 6,514/month | 78,167/year |
| PR     |               8,440 |   767/month |  9,207/year |
| TR     |              15,797 | 1,436/month | 17,233/year |

本报告用这些 output 数据估算 CBSA/partners 的实际处理能力。

## 3. 为什么 post-C12 asylum security referral 估为约 56,000/year

这个数字需要单独说明，因为它是整个模型的基础。

### 3.1 2025 基准：97,600 asylum/refugee security referrals

CSIS 2025 public report 显示，2025 年 **Refugees / Front-End Screening** 为 **97,600 received**。因此，2025 年 asylum/refugee security referral 基准为：

**97,600/year**。([Canada][1])

### 3.2 Bill C-12 的 one-year ineligibility 会减少进入 IRB/security referral 的案件

Bill C-12 于 **2026 年 3 月 26 日**获得 Royal Assent。IRCC 官方说明，新的 asylum eligibility requirements 已生效，并适用于 **2025 年 6 月 3 日或之后 made 的 claims**；其中，首次入境加拿大超过一年后才提出的 asylum claim **won’t be referred to the IRB**。([Canada][2])

这意味着 Bill C-12 的影响位置在：

**claim submitted → eligibility check → eligible claims referred to IRB / front-end security screening**

也就是说，Bill C-12 会在 security referral 之前减少进入后续流程的案件量。

### 3.3 政府材料给出的受影响比例：约 41% 不在 12 个月内 claim

加拿大政府 CIMM 材料显示，2025 年 **59%** 的 inland claimants 在入境 12 个月内提出 claim，而 2024 年该比例为 85%；同时，2025 年等待 **12 个月或更久** 才提出 claim 的比例上升到 **38%**，2024 年为 12%。材料还说明，这意味着越来越多人可能落入 Bill C-12 的新 ineligibility provisions。([Canada][3])

为了建模，本报告采用最简单的比例逻辑：

**post-C12 remaining flow ≈ 59%**

因此：

**97,600 × 59% = 57,584**

考虑到口径差异、rounding、eligibility timing lag、adult/FESS 覆盖范围差异、PRRA 及其他 residual workload，本报告将该结果简化为：

**post-C12 asylum security referral ≈ 56,000/year**

这里必须强调：**56,000/year 不是政府官方预测，而是基于政府公开比例推导出的情景假设。**

## 4. 为什么 future asylum pressure 可能继续下降

除了 Bill C-12 本身，未来 asylum claim 和 asylum security referral 还可能继续下降，原因是 temporary resident pool 已经开始下降。

加拿大政府 CIMM 材料显示，2025 年 1–9 月 total asylum claims 为 **90,310**，相比 2024 年同期的 **133,465** 下降约 **32%**。同一材料还说明，temporary resident visa holders 的 asylum claims 从 2024 年 1–9 月的 **80,765** 下降到 2025 年同期的 **27,595**，下降 **66%**。([Canada][3])

Statistics Canada 数据显示，加拿大 non-permanent residents 从 **2024 年 10 月 1 日的 3,149,131** 下降到 **2026 年 1 月 1 日的 2,676,441**；仅 2025 年第四季度，non-permanent residents 就减少 **171,296**。([Statistics Canada][4])

因此，未来 asylum pressure 下降不只是 Bill C-12 的结果，而是三股力量叠加：

**Bill C-12 eligibility bar + temporary resident population 下降 + TRV-holder asylum claims 下降**

这使得 **56,000/year** 作为 post-C12 asylum security referral 情景并不激进；如果 TR pool 继续下降，实际 asylum security referral 甚至可能低于这一水平。

---

## 5. 2026 asylum intake further decline scenario

前文使用 **56,000/year** 作为 post-Bill C-12 的基准情景。这个数字是从 2025 年 asylum/refugee security referral **97,600** 出发，再套用 **59% remaining flow** 得出。

但这个基准情景可能仍然偏保守，因为它本质上仍以 2025 年 security referral 为起点。2026 年前端 asylum intake 已经明显低于 2024–2025 年高峰。

IRCC spreadsheet 显示，2026 年 Jan–Feb asylum claimants received 合计为 **11,055**。 IRB recent trends 数据显示，2026 年 RPD intake 为 Jan **6,491**、Feb **5,825**、Mar **5,867**；IRB 定义 RPD intake 为 “the number of cases received by the RPD.” 因此，2026 Jan–Mar IRB RPD intake 合计为：

**6,491 + 5,825 + 5,867 = 18,183**

年化后为：

**18,183 / 3 × 12 = 72,732/year**。

这说明 2026 年前端 asylum intake 的运行速度，已经远低于 2025 年 asylum claimants received **113,105/year**，更远低于 2024 年 **171,840/year**。

如果再把 Bill C-12 one-year ineligibility 的 **59% remaining flow** 套到 2026 年前端 intake 年化值上：

**72,732 × 59% = 42,912/year**

也就是说，在一个更低位但并非不合理的情景中，post-C12 asylum security referral 可能不是 **56,000/year**，而是接近：

**43,000/year**

这里也要强调：**43,000/year 不是官方预测值**。它是一个 pressure-test scenario，逻辑是：

**2026 Jan–Mar asylum intake annualized × post-C12 remaining share**

## 6. 可释放 capacity 应该怎么算

不能用：

**97,600 - 56,000 = 41,600**

这个数字只是 **新增 referral 下降量**，不是 CBSA/partners 真正可转移的处理能力。

更合理的算法是：

**2025 asylum security output 年化能力 - future asylum security referral**

根据 Security-Screening PDF，2025 Jan–Nov asylum security output 为 **71,653**。年化后：

**71,653 / 11 × 12 = 78,167/year**

如果 future asylum security referral 为 **56,000/year**：

**78,167 - 56,000 = 22,167/year**

也就是说，理论上每年可以释放约 **22,167** 件处理能力，月均约：

**22,167 / 12 = 1,847/month**

这是本报告用于 PR/TR capacity reallocation 的核心数字。

如果 future asylum security referral 进一步下降，可释放 capacity 会更高：

| 情景                      | Future asylum security referral | 可释放 capacity = 78,167 - referral |
| ----------------------- | ------------------------------: | -------------------------------: |
| 基准情景                    |                     56,000/year |                  **22,167/year** |
| 下降情景 1                  |                     50,000/year |                  **28,167/year** |
| 下降情景 2                  |                     45,000/year |                  **33,167/year** |
| 2026 intake-adjusted 情景 |                     43,000/year |                  **35,167/year** |
| 低位情景                    |                     40,000/year |                  **38,167/year** |

因此，**56,000/year 是相对保守的 post-C12 baseline scenario**。如果 2026 asylum intake 继续下滑，实际可释放 capacity 可能不是 **22k/year**，而是 **28k–38k/year**。

## 7. PR/TR 当前处理能力基准

Security-Screening PDF 显示，2025 Jan–Nov PR output 为 **8,440**，TR output 为 **15,797**。年化后：

| 类别 | Jan–Nov output |       年化 output |
| -- | -------------: | --------------: |
| PR |          8,440 |  **9,207/year** |
| TR |         15,797 | **17,233/year** |

所以，2025 年 PR/TR security screening 的基准处理能力大约是：

**PR：9.2k/year**
**TR：17.2k/year**。

## 8. Capacity 分配假设：TR 优先，PR 次之

本报告假设释放出的 asylum capacity 不会全部给 PR，也不会全部给 TR。

更合理的分配逻辑是：**TR 优先级高于 PR**。原因是 TR 涉及访客、学生、工签、临时入境和短周期决策；PR 虽然重要，但系统通常更能容忍较长等待。

因此，本报告设置三个分配情景：

| 情景          |   TR 分配 |   PR 分配 |
| ----------- | ------: | ------: |
| PR-friendly |     60% |     40% |
| 中性          | **70%** | **30%** |
| TR-priority |     80% |     20% |

后续预测主要使用 **TR 70% / PR 30%** 作为中性情景。

## 9. 基准情景：asylum referral = 56,000/year

在 56,000/year 情景下，可释放 capacity 为：

**78,167 - 56,000 = 22,167/year**

如果按 **TR 70%、PR 30%** 分配：

**PR additional capacity = 22,167 × 30% = 6,650/year**
**TR additional capacity = 22,167 × 70% = 15,517/year**

对应 PR/TR 年处理能力：

| 类别 | 2025 基准年处理量 | 额外 capacity |          预测年处理量 |      预测月处理量 |

| PR |       9,207 |      +6,650 | **15,857/year** | 1,321/month |
| TR |      17,233 |     +15,517 | **32,750/year** | 2,729/month |

## 11. PR security screening 周期预测

Security-Screening PDF 显示，截至 2025-Nov，PR historical inventory 为 **23,406**；同一页的 PR 图表显示，按 last month output 计算，PR with-partners queue 需要约 **54.8 months**。

如果用 2025 Jan–Nov 的 PR 月均 output **767/month** 计算：

**23,406 / 767 = 30.5 months**

因此，PR 当前高压状态可以理解为：

**约 30–55 months**

### 11.1 静态库存口径

如果只看现有 PR inventory **23,406**，不同 future asylum referral 情景下的 PR 处理周期如下：

| Future asylum referral |   PR 新月处理能力 | PR inventory 23,406 对应周期 |
| ---------------------: | ----------: | -----------------------: |
|                 56,000 | 1,321/month |          **17.7 months** |
|                 50,000 | 1,471/month |          **15.9 months** |
|                 45,000 | 1,596/month |          **14.7 months** |
|                 43,000 | 1,646/month |          **14.2 months** |
|                 40,000 | 1,721/month |          **13.6 months** |

### 11.2 动态流入口径

但 PR 每年仍然会有新增 referral。CSIS 2025 public report 显示，PR security screening 为 **15,200 received**、**16,900 completed**。因此，实际周期不应简单看“现有库存 / 新月处理量”，还要考虑持续新增流入。([Canada][1])

因此，本报告给出的 PR 实际预测为：

| Future asylum referral 情景    |          PR 实际预测 |
| ---------------------------- | ---------------: |
| 56k baseline                 | **18–24 months** |
| 50k scenario                 | **16–22 months** |
| 45k scenario                 | **15–20 months** |
| 43k intake-adjusted scenario | **14–20 months** |
| 40k low scenario             | **13–18 months** |

结论：**PR 安调预计会改善，但不会立刻变成 6–12 个月。基准情景是 18–24 个月；如果 2026 asylum intake 继续下降，PR 可能改善到 14–22 个月区间。**

## 13. Timing：为什么 2026 不会立刻全部体现

Bill C-12 是 **2026 年 3 月 26 日**才获得 Royal Assent。虽然新的 eligibility requirements 适用于 **2025 年 6 月 3 日或之后 made 的 claims**，但实际效果需要经过 officer guidance、eligibility review、ineligible case handling、IRB referral reduction、security referral reduction 等环节后才会完整体现。([Canada][2])

因此，合理时间线是：

| 时间         | 预期变化                                                  |
| ---------- | ----------------------------------------------------- |
| 2026 Q2    | C-12 eligibility rules 开始实际影响 claim/referral pipeline |
| 2026 Q3–Q4 | asylum security referral 下降更明显，TR 可能先受益               |
| 2027       | PR 更可能明显受益于 capacity reallocation                     |

换句话说，C-12 对 PR/TR 安调的影响不是“法律一通过就立刻出坑”，而是一个 **6–18 个月逐步传导** 的过程。

---

## 14. Final Assessment

本报告的最终判断是：

**Bill C-12 加上 temporary resident population 下降，将使 asylum/refugee front-end security screening 的新增压力在 2026–2027 年显著下降。**

在 post-C12 asylum security referral 约 **56,000/year** 的基准情景下，若 CBSA/partners 维持 2025 年 asylum output 年化约 **78,167/year** 的处理能力，则理论上每年可释放约 **22,167** 件处理能力。

如果这部分 capacity 按 **TR 70%、PR 30%** 分配，则：

| 类别 | 2025 基准处理能力 |        中性预测处理能力 |             周期预测 |
| -- | ----------: | --------------: | ---------------: |
| PR |  9,207/year | **15,857/year** | **18–24 months** |
| TR | 17,233/year | **32,750/year** | **13–22 months** |

如果 2026 asylum intake 继续下降，并且 future asylum security referral 落到 **43,000–50,000/year**，则：

| 类别 | Further decline scenario 处理能力 |             周期预测 |
| -- | ----------------------------: | ---------------: |
| PR |          约 17,657–19,757/year | **14–22 months** |
| TR |          约 36,950–41,850/year | **10–19 months** |

最主要的不确定性有三点：

1. **56,000/year 或 43,000–50,000/year 的 post-C12 asylum security referral 情景是否成立；**
2. **CBSA/partners 是否能维持 2025 asylum output 年化约 78,000/year 的能力；**
3. **释放出的 capacity 是否能真正转向 PR/TR，而不是被 asylum backlog、PRRA、removals、litigation 或其他 enforcement priorities 吸收。**

总体来说，比较稳妥的结论是：

**TR security screening 大概率先改善，PR security screening 会滞后改善。PR 不太可能迅速下降到 6–12 个月，但从 30–55 个月改善到 18–24 个月是合理的 baseline；如果 2026 asylum intake 继续下降，PR 有机会进一步改善到 14–22 个月，TR 则可能改善到 10–19 个月。**
